단계명칭주요 행동담당저장소
1회원가입사용자 정보 입력 · 계정 생성지현 현표 새봄회원정보 DB
2초기 설문PHQ-9 / GAD-7 정신건강 평가다은 현표설문 결과 DB
3진단 에이전트설문 기반 상태 진단 · 점수 산출다은 지현정신건강 진단 DB
4프롬프트 생성개인 기반 맞춤 상담 프롬프트 생성 (RAG)다은프롬프트 템플릿 DB
5AI 상담 대화실시간 상담 + 위기 감지 프로토콜 상시 작동다은 지현 현표대화 로그 DB
6상담 종료대화 요약 · 상태 업데이트 · 연속성 데이터 저장다은 지현상담 요약 DB
위기 개입 시스템 (3주차 내 필수 완성): score < 0.4 → 확인 질문 / 0.4~0.7 → 앱 내 안내 + 1393 자살예방상담전화 안내 / 0.7~0.9 → 보호자 알림 (동의 기반) / 0.9 이상 → 즉시 Function Calling (1393 직연결 + 주변 기관 안내). 오탐 방지를 위해 키워드 단독 감지 금지, 문맥 분석 필수.

오픈 이슈 — D1 전원 결정 필요

이슈상세 내용우선순위권장 방향
진단 방식 결정 설문 단독 vs 대화 기반 진단 병행 여부. 실시간 상태 업데이트 로직. 높음 3주 안에는 설문 단독으로 시작. 대화 기반 업데이트는 4주차 이후 추가 권장.
복합 질환 처리 PHQ-9 + GAD-7 동시 높음 시 프롬프트 우선순위 결정. Agent vs RAG 방식 선택. 높음 PHQ-9 우선 + GAD-7 보완 방식으로 확정. RAG는 1주차 말까지 프로토타입.
페르소나 설정 사용자 커스터마이징 범위 정의. 상담사 스타일 선택지 설계. 중간 3주 안에는 프리셋 3종(공감형/코칭형/중립형)으로 제한. 완전 커스텀은 4주차.
병원 정보 연계 위기 상황 시 주변 병원 정보 제공. 데이터 소스 및 업데이트 주기. 중간 3주 안에는 1393 · 정신건강 위기상담전화만 하드코딩. 위치 기반 병원 연계는 4주차.
보호자 연결 설계 동의 기반 보호자 알림. 미성년자 별도 플로우 필요성. 낮음 3주 안에는 성인 기준 SMS 알림만 구현. 미성년자 플로우는 4주차 이후.
STT 엔진 선택 Whisper API vs Clova Speech. 레이턴시 3초 이내 목표. 높음 D1에 두 엔진 latency 테스트 후 결정. 국내 서버 응답 속도 우선이면 Clova 권장.

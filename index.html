HIGHSTT / TTS 파이프라인
스피커 기반 서비스의 핵심인데 역할 분담 어디에도 없음. Whisper(OpenAI) 또는 Clova Speech(네이버) 선택 + TTS 엔진(Clova/Azure) 연동 필요. 백엔드 ②에 즉시 추가.
HIGHWebSocket 실시간 통신
스피커 ↔ 서버 간 음성 스트리밍은 REST가 아닌 WebSocket 필수. 지연 없는 대화를 위해 FastAPI WebSocket 엔드포인트 설계가 필요. 현재 "REST 엔드포인트"만 명시돼 있음.
HIGH보호자 / 전문가 포털 UI
프론트엔드 항목에 사용자용 UI만 있음. 보호자 주간 리포트, 위기 알림 페이지, 전문가용 고위험군 대시보드가 완전히 누락. 3포털이 핵심 차별점인데 개발 계획 없는 상태.
MEDIUM알림 시스템
보호자에게 위기 알림·안부 알림 발송하는 시스템 없음. SMS(coolSMS 등), 이메일, 앱 푸시(FCM) 중 선택 필요. Celery로 비동기 처리 가능하지만 설계가 명시돼야 함.
MEDIUM음성 비언어 분석
서비스 핵심 차별점 중 하나. pyAudioAnalysis / librosa로 음높이·속도·음량 특성 추출 후 진단 에이전트에 투입하는 파이프라인 필요. 현재 어떤 역할에도 없음.
MEDIUM비접속 자동 감지
3일+ 스피커 미사용 시 보호자 알림 발송 로직. Celery Beat 스케줄러로 구현 가능하지만 DB 설계(마지막 접속 시각 저장)와 알림 임계값 정책이 명시돼야 함.
MEDIUMOTP/PIN 인증
노인용 서비스에서 일반 비밀번호는 취약점. 전화번호 기반 OTP 또는 PIN 4~6자리 인증으로 교체 필요. DB/보안 ③에 추가. 세션 토큰 만료 시간도 일반보다 길게 설정.
LOW음성 원본 스토리지
음성 원본 저장 정책(S3 또는 MinIO), 암호화(AES-256), 감사 로그, 6개월 자동 삭제 Celery 태스크. 개인정보보호법상 생체정보 처리 별도 동의 및 보관 기간 명시 의무.
LOW텍스트 폴백 UI
STT 실패(보청기·발음 불명확) 시 자동으로 텍스트 입력 모드 전환. 노인 접근성의 핵심. 프론트엔드 ④에 추가. 큰 버튼 + 단순 입력 UI 필요.
4인 기준 약 12주 일정 (주 단위). 병렬 진행 표시.

뭐부터 시작해야 하는지 — 이전 단계가 완료돼야 다음이 가능한 순서.
1
DB 스키마 설계 + FastAPI 기본 서버
모든 기능의 토대. 사용자 테이블, 세션 테이블, 진단 이력 테이블, RBAC 권한 테이블을 먼저 확정해야 이후 모든 API가 흔들리지 않음. ③④ 동시 시작.
③ DB 설계② FastAPI 서버1~2주
2
STT / TTS 파이프라인 + WebSocket 연결
스피커 기반 서비스의 핵심 파이프라인. 음성→텍스트→LLM→텍스트→음성 흐름이 동작해야 나머지 모든 AI 기능을 테스트할 수 있음. 이게 없으면 Claude API 연동 테스트도 불가.
② STT/TTS② WebSocket2~3주
3
OTP/PIN 인증 + Claude API 기본 연동
사용자 인증 없이는 세션 관리가 불가. 노인 친화적 OTP 인증 먼저 구현. 동시에 Claude API 기본 연동 테스트(프롬프트 in → 응답 out). 이 단계에서 첫 번째 "말하고 대답 듣기" 데모 가능.
③ OTP 인증② Claude API① 기본 프롬프트3~4주
4
진단 에이전트 + 프롬프트 라우팅 순환 구조
PHQ-9 점수 → 진단 → 프롬프트 조정 → 대화 → 요약 → 재진단의 순환 루프. 이게 완성돼야 "AI가 상태에 맞게 대화한다"는 핵심 가치 제안이 작동함. 병행: 사용자 UI MVP.
① 진단 에이전트④ 사용자 UI4~6주
5
위기 감지 2단계 로직 + Function Calling
score 계산 → 분기(확인 질문 / 보호자 알림 / 119 연결). 법적·윤리적으로 반드시 오탐 방지 로직이 있어야 서비스 공개 가능. 이 기능 없이 배포하면 안 됨.
① 위기 로직② Function Calling6~8주
6
보호자 포털 + 알림 시스템
경쟁사 6곳 전무한 차별점. B2G 영업 시 "보호자가 확인할 수 있다"는 데모가 핵심. 주간 리포트 UI + SMS/FCM 알림 발송. 비접속 Celery Beat 태스크도 여기서 완성.
④ 보호자 포털②③ 알림8~10주
7
전문가 포털 + 통합 테스트 + 배포
지자체 공무원·복지사 대시보드. 고위험군 목록, 개입 기록, 보고서 자동 생성. 이후 전원이 참여하는 통합 테스트(실제 노인 사용자 대상 포함) → HTTPS 배포 → 지자체 데모.
④ 전문가 포털③ 보안·배포10~12주
